# 🚀 Personal Dev Showcase

Ласкаво прошу до мого `монорепозиторію` програмних проєктів. Цей простір створений для демонстрації моїх навичок у `Full-stack розробці`, з акцентом на чистий код, архітектурну гнучкість та автоматизацію.

## 📂 Структура репозиторію
### 1. 🏠 Personal Page
Центральний хаб мого портфоліо.
*   **Призначення:** Презентація досвіду, технічного стеку та засобів зв'язку.
*   **Останні оновлення:** 
    *   Впроваджено анімований `WakeUpLoader` для нівелювання ефекту "холодного старту" на безкоштовних PaaS (Render/Vercel).
    *   Контактна форма винесена в окремий сервіс `useContactForm` для кращої підтримки коду.

### 2. ☀️ Solar Power Calculator
Аналітична платформа для моніторингу та розрахунку ефективності сонячних електростанцій.
*   **Призначення:** Збір даних про генерацію, фінансовий облік та аналітика продуктивності.
*   **Ключові можливості:**
    *   **Dashboard:** Віджет `MonthStats`, що в реальному часі порівнює поточну генерацію з минулим місяцем у відсотках.
    *   Реалізовано систему закріплених повідомлень (`MessagesStack`) з іконками типів подій (success, info, warning, error).
    *   **Smart Table:** Таблиця записів з інтелектуальними бейджами статусів (`NOT TRACKED`, `NO GENERATION`) та контекстною індикацією кольорів.
    *   **Backend Analytics:** Обчислення кількості сонячних днів, середніх температур, загальної потужності та вартості виробленої електроенергії на боці Django за допомогою методів моделей.

## 🔧 Встановлення та запуск (Local Development)

### 🐍 Бекенд (Django)
1. Встановіть залежності:
   ```bash
    pip install -r requirements.txt
   ```

2. Виконайте міграції:
    ```bash
    python manage.py migrate
    ```
   
3. Запустіть сервер:
    ```bash
    python manage.py runserver
   ```
   
### ⚡ Фронтенд (Vite + Vue 3)

1. Встановіть пакети:
    ```bash
    yarn install   
   ```
   
2. Запустіть сервер розробки з доступом по локальній мережі:
    ```bash
    yarn dev --host 0.0.0.0 --port 5173
   ```
